# docs/

경력기술서 작성을 위한 기초 자료 및 의사결정 기록.

| 파일 | 목적 |
|---|---|
| [`profile.md`](profile.md) | 인적사항·연락처·기술 스택·자격 등 기본 이력 사실 |
| [`career-facts.md`](career-facts.md) | 회사·프로젝트별 실제 수행한 업무의 원자료 (이력서에 반영할지 여부와 무관하게 사실만 기록) |
| [`decisions.md`](decisions.md) | 이력서 구조·표현·전략에 관한 의사결정 기록 (왜 그렇게 썼는가) |

## 원칙

- `profile.md`, `career-facts.md`는 **사실**만 기록. 이력서용 표현이 아닌 원천 정보.
- `decisions.md`는 **선택과 근거**를 기록. 다음번 이력서 수정 시 같은 고민을 반복하지 않도록.
- 이력서 본문(`index.md`, `index.v2.md`, `index.html`)은 위 자료를 가공한 결과물.
